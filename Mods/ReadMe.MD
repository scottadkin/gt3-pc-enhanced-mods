## Save Game Warning
- If you save the game with one of these mods with an upgrade that doesn't exist in the stock game, the garage will crash if the mod is not enabled.

## Installing Mods
- Create a folder in the same directory where gt3pc.exe and gt3launcher.exe. 
- Extract the contents of a .zip into the folder you just created.
- Use the launchers mod manager to enable or disable the folder for the changes to take effect.

## No Rubberband
Removes AI rubberband if you get too far ahead or too far behind.

## Remove AI Handicaps & No Rubberband
Removes max throttle limits ai cars have in some events and sets other stats to 100%. Includes remove rubberband.

## Give-All-AI-Most-Powerful-Turbo-Upgrades
Every AI car gets the most powerful turbo and intercooler upgrades.
